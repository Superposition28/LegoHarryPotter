LEGO Harry Potter — Game Files & Combined Directory Architecture

Architecture Concept: Unified representation of Source and Extracted Archive Data

The Combined Virtual Filesystem Concept

In retail distributions of TT Games titles, game assets are packed inside monolithic or multi-slice archive volumes (GAME*.DAT, INSTALL*.DAT, or *.datwin) or stored directly in the Xbox XDVDFS partition (in LSW1 and LSW2 Xbox/Xbox 360). This documentation presents the game's file structure using a combined virtual filesystem where archive packages are transparently replaced by their extracted directory trees.
