Project: LEGO Harry Potter Reversing & Format Documentation

Project Mission & Architectural Principles

This technical reference documents binary file formats, proprietary archive packaging, compression algorithms, and filesystem structures for LEGO Harry Potter within the RemakeEngine ecosystem. It follows the reverse-engineering documentation standards established across the LEGO and Simpsons documentation repositories.

Two Complementary Documentation Trees

  1. Format Analysis (Formats/): Follows binary format origins: root executable and container formats (.xex/.xbe, .bin/ELF, .exe, .dat/.hdr/.datwin) followed by formats extracted from within archives (datFormats/), explicitly noting which formats are universal across TT Games and which are specific to certain eras or titles.
  2. Game Files & Asset Use (Files/): Documents directory hierarchies, cross-game format censuses, sound banks, character definitions, mission scripts, and in-game usage through a combined virtual filesystem.
