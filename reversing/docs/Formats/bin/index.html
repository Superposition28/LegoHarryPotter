SELF & PARAM.SFO Header Layout

PARAM.SFO (\x00PSF) & SCE/SELF Header Fields
Offset Size Type Field Description
SELF+0x00 4 char[4] magic "SCE\0" (big-endian PS3 Signed ELF header, followed by version/keys/ELF header offset).
SFO+0x00 4 char[4] sfo_magic 0x00 0x50 0x53 0x46 (\x00PSF).
SFO+0x08 4 / 4 / 4 u32le[3] key_off, data_off, count Offsets to UTF-8 key table, data payload table, and entry count.
SFO+0x14+i*16 16 struct SfoEntry k_rel(u16), fmt(u16: 0x0204 str / 0x0404 u32), d_len(u32), d_max(u32), d_rel(u32).

Cross-Format Relationships & Dependencies

Referenced By (Upstream Containers / Loaders)

  • ISO-9660 / PKG — PS3 discs boot PS3_GAME/USRDIR/EBOOT.BIN; PSN releases wrap encrypted NPDRM SELF.

References (Downstream Assets / Sub-Formats)

  • .DAT / .HDR Archives — Bootstraps virtual filesystem and mounts localized audio/patch volumes.
  • EdFile / Reflection Engine — Built-in StreamInfo class registry initializes RTTI factories at boot.

Filtering, Edge Cases & Unresolved Fields

  • Retail disc EBOOT.BIN SELF payloads are NPDRM/ECDSA-signed by Sony; inspection via PARAM.SFO + ISO directory walk does not require breaking disc keys because Redump PS3 ISOs store unencrypted PARAM.SFO and GAME*.DAT data files.

Standalone Clean-Room Parser Pseudocode

function ParseParamSfo(buf):
    if buf[0:4] != b"\x00PSF": return {}
    ver, key_off, data_off, cnt = ReadU32LE4(buf, 4)
    out = {}
    for i in 0 .. cnt - 1:
        k_rel, fmt, d_len, d_max, d_rel = ReadStructure("<HHIII", buf, 20 + i*16)
        k = ReadNullAscii(buf, key_off + k_rel)
        raw = buf[data_off + d_rel : data_off + d_rel + d_len]
        out[k] = raw.rstrip(b"\0").decode("utf-8") if fmt == 0x0204 else ReadU32LE(raw, 0)
    return out
