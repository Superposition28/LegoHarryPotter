Key Configuration Files

  • STUFF/GAME.TXT & LEVELS.TXT: Master campaign flow, hub links, and gameplay constants.
  • 360_exlist (LSW2 Xbox 360): 42-line extension translation map converting legacy PS2/Xbox extensions (ghg, gsc, ter, cu2, an3, vag) into Xbox 360 equivalents (ctr, cc2, ca3, xma).
  • FILETABLE.TXT & TRACKEDFILELIST360.TXT (Batman 2 PC): Developer build manifests revealing __dlc1__, __dlc2__, and wii\ asset trees.
  • text.csv: Multilingual string table indexed by LABEL across English, French, German, Spanish, Italian, Danish, Dutch, etc.
