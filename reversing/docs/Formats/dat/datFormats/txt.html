Standalone Clean-Room Parser Pseudocode

function ParseKeyValueTxt(text):
    cfg = {}
    for line in text.splitlines():
        if "=" in line and not line.strip().startswith("//"):
            k, v = line.split("=", 1); cfg[k.strip()] = v.strip()
    return cfg
