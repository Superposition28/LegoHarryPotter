Inspected Audio Stream & Bank Formats
Ext Observed Games Header & Encoding
.vag LSW1 PS2 (796), LSW2 PS2 (1,037), BM1 PS3 (641) Sony "VAGp" 48B big-endian header + 4-bit PS-ADPCM 16B blocks; driven on PS2 IOP by SYS/NUSND3G.IRX.
.xsb / .xwb LSW2 PS2 (spotfx.xsb / spotfx.xwb) XACT SoundBank ("KBDS" 29 KB) and WaveBank ("DNBW" 29.6 MB) packed inside PS2 GAME.DAT.
.at9 PS4 LEGO Worlds (snd0.at9, 1.61 MB) RIFF WAVE extended format (wFormatTag = 0xFFFE, 48,000 Hz stereo) Sony ATRAC9 title-screen loop.
.wavx / .wavm LSW1 / LSW2 Xbox Headerless/Xbox ADPCM or WMA stream blocks aligned to Xbox audio sectors (Ep3_VaderFight1.wavx 3.52 MB).
.ogg PC builds, LOTR PS3 (2) Standard Xiph "OggS" Vorbis container.
.raw Indy 2–HP 5–7 (1–2) Headerless 16-bit PCM test/DSP buffers.
.ctr LSW2 360, TCS (293), BM1 (183) Camera/music audio track descriptor (`u32be` header `0x00036F32`, count `9`, `f32be` camera/beat vectors in LSW2 360).

Standalone Clean-Room Parser Pseudocode

function IdentifyStreamAudio(buf):
    if buf[0:4] == b"VAGp": return {codec: "PS_ADPCM", rate: ReadU32BE(buf, 16)}
    if buf[0:4] == b"OggS": return {codec: "OggVorbis"}
    if buf[0:4] == b"MSFC": return ParseMsf(buf)
    return {codec: "RawOrXboxADPCM", size: len(buf)}
