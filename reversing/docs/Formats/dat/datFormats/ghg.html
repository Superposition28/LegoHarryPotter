1. NU20 Character Rigging & Rigid Part Transform

Classic .ghg files open with u32le nu20_rel (pointing to "NU20"), u16le n_tex, sequential 24B + DDS texture slices (cubemaps advance tex_idx += 6 when signed width < 0), length-prefixed Vertex Buffers, and UInt16 Index Buffers. Inside NU20, chunk "GSNH" stores:

GSNH Rigging & Command Offsets (Relative to GSNH Tag)
Offset Type Field Formula / Purpose
+280 i32le r280 Points to display command header: hdr = GSNH+280+r280; cmd_base = hdr+8+I32(hdr+8), materials at c0 == 0x380.
+368 u32le nbones Skeleton bone count (1..512).
+380 i32le m2_rel Array of nbones * 64B row-vector 4×4 inverse bind matrices; invert rigid 3×3 transpose + -R^T*p to place limb vertices in character world space.
+408 / +412 u32le, i32le n_layers, r412 NuLayer table (20B/entry): filters out breakup, medium, lores, c3po, and tt2/3/4 layers while attaching rigid parts per bone.

2. Era 3c–4 HSEM Skinned & LOD Rules

  • Skinned Vertex Split Streams: HSEM characters commonly store positions & bone weights in VB[0] (often BE/LE auto-detected Float32 + skin indices) and normals/colors/UVs in VB[1] matched by equal nv and shared 0xC000xxxx resource IDs.
  • Breakup Chunk Filtering: In LOGH LOD 0 (first ceil(len(submeshes) / n_logh)), when ≥ 3 submeshes carry bone influence (blen > 0), all unskinned blen == 0 debris/breakup chunks are discarded.
  • Marvel 1+ Bridge (ver >= 0xA9): Inserts "DXTV" + u32be desc_ver (<= 0x2D fixed 16×2B slots vs dynamic attr count + 6B footer) on every Vertex Buffer.

Cross-Format Relationships & Dependencies

Referenced By (Upstream Containers / Loaders)

  • .cd / .cpd Definitions — Character and customizable part definitions load char meshes by name.
  • .res Manifests — Hobbit/Dimensions .res graphs list .ghg alongside .an4 and .nxg_textures.

References (Downstream Assets / Sub-Formats)

  • .an3 / .an4 Animations — Skeletal bone transforms target bones matching GSNH / HSEM joint names.
  • .dds / .tex / .nxg_textures — Embedded DDS slices or external platform textures bound by slot index.
  • .ps3_shaders / .pc_shaders — Character surface shaders resolved in Era 3c–4.

Filtering, Edge Cases & Unresolved Fields

  • All-Black Color Override: UByte4 vertex colors where R==G==B==0 represent unbaked white (1.0, 1.0, 1.0) on NXG minifigure meshes.
  • Empty Proxy Locators: Small <1 KB .ghg files act as collision/camera locators with 0 draw meshes; return empty list cleanly.

Standalone Clean-Room Parser Pseudocode

CONST TYPE_SIZES = [0, 4, 8, 12, 16, 4, 8, 4, 4, 4, 4, 2]

function ParseGhgCharacter(bytes):
    prims = ParseNu20Character(bytes)
    if len(prims) > 0: return prims
    return ParseHsemStream(bytes, filter_logh_lod0=True, drop_breakup_if_skinned=True)

function InvertRigidMat4x4(m):
    r_inv = [m[0], m[4], m[8],  m[1], m[5], m[9],  m[2], m[6], m[10]]
    tx = -(m[12]*m[0] + m[13]*m[1] + m[14]*m[2])
    ty = -(m[12]*m[4] + m[13]*m[5] + m[14]*m[6])
    tz = -(m[12]*m[8] + m[13]*m[9] + m[14]*m[10])
    return (r_inv, [tx, ty, tz])

function DecodeTriangles(raw, vcnt, is_strip, clockwise_target):
    out = []; n = len(raw)
    if is_strip:
        for s in 0 .. n - 3:
            a, b, c = raw[s], raw[s+1], raw[s+2]
            if 0 <= a < vcnt and 0 <= b < vcnt and 0 <= c < vcnt and a != b and b != c and a != c:
                ccw_even = ((s & 1) == 0)
                emit_abc = (ccw_even and not clockwise_target) or (not ccw_even and clockwise_target)
                out.extend((a, b, c) if emit_abc else (a, c, b))
    else:
        for i in range(0, n - (n % 3), 3):
            a, b, c = raw[i], raw[i+1], raw[i+2]
            if 0 <= a < vcnt and 0 <= b < vcnt and 0 <= c < vcnt and a != b and b != c and a != c:
                out.extend((a, c, b) if clockwise_target else (a, b, c))
    return out

function ParseNu20Character(bytes):
    if len(bytes) < 8: return []
    nu_off = ReadU32LE(bytes, 0) + 4
    if nu_off < 8 or bytes[nu_off : nu_off+4] != b"NU20": return []
    dds_by_slot, vbs, ibs = ReadNuPreambles(bytes, 4, nu_off)
    tail = bytes[nu_off:]; gsnh = FindTag(tail, b"GSNH")
    nbones = ReadU32LE(tail, gsnh + 368)
    m2_ptr = gsnh + 380 + ReadI32LE(tail, gsnh + 380)
    world_binds = [InvertRigidMat4x4(ReadF32LE16(tail, m2_ptr + b*64)) for b in 0..nbones-1]
    // Resolve GSNH+280 command ring (0x380 materials, 0x8E sentinel) and GSNH+412 NuLayer filters
    return ExtractNuPrimitives(tail, gsnh, vbs, ibs, world_binds, dds_by_slot)
