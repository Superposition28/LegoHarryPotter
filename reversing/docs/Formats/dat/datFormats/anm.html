Binary Layout (Verified in new_town.anm & botanicgardens_a.anm)

.anm File & Record Structure
Offset Size Type Field Description
0x00 4 u32le version Observed constant 6 across TCS and BM1.
0x04 4 u32le count Number of 96-byte prop entries (e.g. 21 in new_town.anm: 8 + 21*96 = 2,024 + 40B tail).
Entry+0x00 36 ASCII node_name Null-padded scene object identifier (e.g. "Pop_2_House_4", "greenpumpnull1") + group index.
Entry+0x2C 24 ASCII event_tag Animation/SFX trigger label (e.g. "EVAP_POP_2", "GOOPSTEP").
Entry+0x3C 4 u32le frames Observed 0x3C (60 frames / 1.0s) or flags.
Entry+0x40..0x5F 32 f32le[] delta_vec Translation / impulse deltas (e.g. small float32 motion vectors).

Filtering, Edge Cases & Unresolved Fields

  • Tail Bytes: new_town.anm (2,064 B for 21 entries) includes a 40-byte trailer after 8 + count * 96; treat bytes beyond 8 + count * 96 as optional level footer flags.

Standalone Clean-Room Parser Pseudocode

function ParseAnm(buf):
    ver, count = ReadU32LE2(buf, 0)
    entries = []
    for i in 0 .. count - 1:
        off = 8 + i * 96
        node = ReadNullAscii(buf, off, 32)
        tag = ReadNullAscii(buf, off + 0x2C, 20)
        frames = ReadU32LE(buf, off + 0x3C)
        entries.append({node: node, tag: tag, frames: frames})
    return entries
