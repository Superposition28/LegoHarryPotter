.anm (Animation Track Sequence)

Category: Animation · Extracted from TT Games .DAT / .datwin archives

Format Specification · TT Games Engine

Keyframe skeletal animation sequence defining bone rotations (quaternions), translations, and scale curves over time for minifigures, vehicles, and creatures.

File Extension
.anm
Header Signature / Magic
0x06000000
Subsystem
Animation

Overview

.anm files animate skeletal hierarchies defined in .ghg files. Standard minifigure animations (run, jump, build, attack, cast spell, idle) are shared across titles via character definition scripts.

Structure

Headers begin with frame count, sampling rate (typically 30 or 60 FPS), and track channel counts. Channels store timestamped quaternion rotation tracks (x, y, z, w) and vector translations.
