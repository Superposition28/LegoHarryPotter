Standalone Clean-Room Parser Pseudocode

function ParseBurOrCns(buf, ext):
    if ext == ".bur": return {ver: ReadU32LE(buf,0), floats: ReadF32LEArray(buf, 8, (len(buf)-8)//4)}
    if ext == ".cns": return {ver: ReadU32LE(buf,0), count: ReadU32LE(buf,4)}
