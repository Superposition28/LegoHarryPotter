Cross-Format Relationships & Dependencies

Referenced By (Upstream Containers / Loaders)

  • Console Store / Optical Disc — Installed to console storage (PS3 dev_hdd0, PS4 /user/app, Xbox 360 Content/0000000000000000).

References (Downstream Assets / Sub-Formats)

  • .DAT / .HDR / .CC40TAD — Contains base/patch/DLC asset archives inside decrypted PS3/PS4/X360 containers.

Filtering, Edge Cases & Unresolved Fields

  • PS4 Inner PFS Encryption Boundary: Unencrypted \x7fCNT entry metadata (PARAM.SFO, PlayGo XML, .dds, .at9, .trp) and outer PFS superblock geometry are directly readable; inner PFS filesystem sectors (mode=0x000D) are AES-XTS encrypted and require dedicated external extraction tools (LibOrbisPkg / PkgTool) with the package passcode.
  • X360 STFS UTF-16BE Alignment: Notice STFS display and title strings begin on odd byte offsets (+0x411 and +0x1691).

Standalone Clean-Room Parser Pseudocode

function ParseConsolePackageHeader(raw):
    m = raw[0:4]
    if m == b"CMP2":
        return {kind: "PS3_CMP2_LZMA", payload: LzmaDecompress(raw[0x20:])}
    if m == b"\x7fCNT":
        ecnt, tbl = ReadU32BE(raw, 0x10), ReadU32BE(raw, 0x18)
        cid = ReadNullAscii(raw, 0x40, 36)
        pfs_off, pfs_sz = ReadU64BE2(raw, 0x410)
        return {kind: "PS4_CNT", cid: cid, entries: ecnt, tbl_off: tbl, pfs_off: pfs_off, pfs_sz: pfs_sz}
    if m == b"LIVE":
        return {kind: "X360_STFS", tid: ReadU32BE(raw, 0x360), disp: raw[0x411:0x491].decode("utf-16be").split("\0")[0]}
    if m == b"\x7fPKG":
        return {kind: "PS3_PKG", items: ReadU32BE(raw, 0x14)}
