Exact Deflate_v1.0 (.an4) Decoding Rule

The C# TTGames-Explorer-Rebirth reference tool stalled on .an4 because standard Zlib rejects the first deflate block header byte. Empirical verification across Hobbit and Dimensions confirms TT Games stores an unframed RFC 1951 Deflate stream at +0x24 whose first byte needs bit 2 inverted (payload[0] ^= 0x04) if direct raw Deflate fails.

Standalone Clean-Room Parser Pseudocode

function DecodeAn4(raw):
    if raw[0:12] != b"Deflate_v1.0": return raw
    usz = ReadU32LE(raw, 0x20)
    payload = raw[0x24:]
    try:
        dec = RawInflate(payload)
    except:
        payload_fixed = Copy(payload); payload_fixed[0] ^= 0x04
        dec = RawInflate(payload_fixed)
    dec = dec[:usz]
    ver, inner_usz = ReadU32BE2(dec, 0)
    return {version: ver, data: dec}
