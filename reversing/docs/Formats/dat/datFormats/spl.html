Binary Layout (Observed in batcave_a.spl)

EDSPLINE v3 Binary Structure
Offset Size Type Field Description
0x00 12 char[12] magic "EDSPLINE v. "
0x0C 4 u32le version Observed version 3.
0x10 4 u32le spline_count Number of splines in file (4 in batcave_a.spl).
0x14+ var u32le + records SplineTable Per-spline name (ASCII), point count, Vec3 world knots, tangent handles, and usage tag (e.g. climb_batman).

Standalone Clean-Room Parser Pseudocode

function ParseSpl(buf):
    if buf[0:12] != b"EDSPLINE v. ": raise NotEdspline
    ver, cnt = ReadU32LE2(buf, 12)
    return {version: ver, spline_count: cnt}
