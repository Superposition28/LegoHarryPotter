RIFF Chunk Structure

XMA RIFF Header (LSW2 X360 Verified)
Offset Size Type Field Description
0x00 12 RIFF..WAVE riff_hdr Little-endian RIFF container size & "WAVE" form.
0x0C 8 "fmt " fmt_hdr Standard fmt chunk (size 0x20 / 0x34).
0x14 2 u16le wFormatTag 0x0165 (XMA1, observed in LSW2 360) or 0x0166 (XMA2).
data var 2KB pkts xma_stream Big-endian 2048-byte XMA packets decoded by Xenon XMA coprocessor.

Standalone Clean-Room Parser Pseudocode

function ParseXma(buf):
    if buf[0:4] != b"RIFF" or buf[8:12] != b"WAVE": raise NotRiff
    wFormat = ReadU16LE(buf, 0x14)
    return {format_tag: wFormat, is_xma: wFormat in (0x0165, 0x0166)}
