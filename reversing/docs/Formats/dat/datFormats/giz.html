Overview & Sub-Chunk Schema

Binary container storing interactive level gizmos per level sub-area. Each section is prefixed by a length-prefixed ASCII type identifier followed by structured placement records:

  • GizObstacle: Interactive obstacles, gates, and hazard volumes.
  • GizBuildit: Multi-brick bouncing LEGO build-it assembly spots.
  • GizForce: Jedi Force / Harry Potter Wingardium Leviosa telekinesis targets.
  • Blowup: Silver/Gold LEGO destructible props and stud drop tables.
  • GizmoPickup, Lever, ZipUp (grapple points), HatMachine, Plug, Tube, and Turret.
