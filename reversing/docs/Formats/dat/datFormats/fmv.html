.fmv files are unmodified RAD Bink streams playable/demuxable directly by FFmpeg after extraction from .DAT or disc FMV/ directories (stored uncompressed codec 0 for streaming playback).

Bink Video (.fmv) Header Offsets
Offset Size Type Description
0x00 4 char[4] "BIKi" / "BIK..." (Bink 1) or "KB2..." (Bink 2).
0x04 4 u32le File size minus 8 bytes.
0x08..0x27 32 u32le[] Frame count, largest frame size, width, height, FPS numerator/denominator, and audio track count.

Standalone Clean-Room Parser Pseudocode

function IdentifyFmv(buf):
    tag = buf[0:4].decode("ascii", "replace")
    return {bink_magic: tag, file_size_minus8: ReadU32LE(buf, 4)}
