Filtering, Edge Cases & Unresolved Fields

  • Pre-2011 Parser Trap: Parsers expecting "SERIALISED" at +0x04 reject Indy 2 and HP 1–4 .dno files; always branch on whether bytes 4..14 equal b"SERIALISED".

Standalone Clean-Room Parser Pseudocode

function ParseDnoHeader(buf):
    if buf[4:14] == b"SERIALISED":
        sz = ReadU32BE(buf, 0)
        sub_ver = ReadU32BE(buf, 15)
        return {envelope: "SERIALISED", size: sz, sub_ver: sub_ver}
    return {envelope: "Direct", ver: ReadU32BE(buf, 0)}
