EdFile StreamInfo Container Structure

EdFile Reflected Header Layout (Shared by .as, .cd, .cpd, .apj, .cpj, .led)
Chunk / Tag Offset Pattern Description
Optional .CC4HSER +0x00 u32be sz, .CC4HSERHSER Added in Era 4 (Marvel 1–Dim) on .as & .cd at offset 0 before StreamInfo (e.g. streaminfo_off=417 in Marvel 1).
"StreamInfo\0" -8 u32le sz, -4 u32le 11 Header size + u32le ver (17..30) immediately after NUL.
"TypeList\0" Primitive sizes u32le count of reflected C++ primitives (Char=1, Short=2, Int=4, Int64=8, Float=4...).
"ClassList\0" Engine classes Named C++ classes, parent class IDs, and property field descriptors.
"OLST" Object List Big-endian serialized object instance graph with animation state nodes and clip filenames.

Cross-Format Relationships & Dependencies

Referenced By (Upstream Containers / Loaders)

  • .cd / .res — Character definition selects primary .as state file.

References (Downstream Assets / Sub-Formats)

  • .an3 / .an4 / .pac — References individual clip filenames and blended transitions.

Filtering, Edge Cases & Unresolved Fields

  • Mixed Endianness Inside EdFile: StreamInfo/TypeList/ClassList reflection dictionary is Little-Endian, whereas outer .CC4HSER (and inner OLST values on PS3/X360) use Big-Endian.

Standalone Clean-Room Parser Pseudocode

function ParseEdFileHeader(buf):
    si = FindTag(buf, b"StreamInfo\0")
    if si < 8: raise NotEdFile
    ver = ReadU32LE(buf, si + 11)
    tl = FindTagFrom(buf, si, b"TypeList\0")
    ol = FindTagFrom(buf, si, b"OLST")
    return {cc4: buf[4:8] == b".CC4", streaminfo_ver: ver, typelist_off: tl, olst_off: ol}
