Font Format Family Comparison

Inspected Font Files
Extension Era Binary Structure
.fnt Era 2 (TCS, BM1) Big-endian glyph sheet (`sysfont_360.fnt`, `batman_font_ps3.fnt`): table offsets at `+0x00/+0x08`, float metrics (42.x/16.x px) at `+0x24`, UV quads + bitmap payload.
.cft Era 2 (TCS, BM1) ASCII/Latin1 character lookup table mapping byte codepoints 0x00..0xFF to glyph indices (0xFF = missing).
.qfn / .ufn Era 2 (TCS) Button/Unicode glyph atlases sharing +0x10 hash/page metrics and IEEE float rect coordinates for HUD prompt glyphs.
.ft2 Era 3a–4 (Indy 2..Dim) Header: u32be metrics_sz, u32be 1, "TNFN", u32be ver(3), "ROTV" glyph rect table, followed by embedded "DDS " (NVTT DXT5 / NU2T) atlas bitmap.

Standalone Clean-Room Parser Pseudocode

function ParseFt2(buf):
    hdr_sz = ReadU32BE(buf, 0)
    if buf[8:12] != b"TNFN": raise NotFt2
    ver = ReadU32BE(buf, 12)
    dds_off = FindTag(buf, b"DDS ")
    return {version: ver, dds: PatchPitchAndDecodeDDS(buf[dds_off:]) if dds_off >= 0 else null}
