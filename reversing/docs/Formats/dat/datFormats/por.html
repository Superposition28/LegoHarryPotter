Binary Header (Observed in 7asgardb.por, 1,046 B)

.por TROP Container Layout
Offset Size Type Field Description
0x00 4 u32be payload_sz Remaining file size minus 4 (0x0412 = 1,042 B).
0x04 4 u32be hdr_ver Observed 1.
0x08 4 char[4] magic "TROP" (byte-swapped "PORT").
0x0C 4 u32be trop_ver Observed 2.
0x10+ var f32be[] / ASCII portals Portal quad bounds/planes and room name strings (e.g. 7asgardb).

Standalone Clean-Room Parser Pseudocode

function ParsePor(buf):
    if buf[8:12] != b"TROP": raise NotTrop
    return {payload_sz: ReadU32BE(buf, 0), trop_ver: ReadU32BE(buf, 12)}
