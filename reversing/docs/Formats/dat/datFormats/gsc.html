2. HSEM Chunk Tree, Vertex Attributes & PSID / LTMU Bindings

HSEM Vertex Attribute Type Table (TYPE_SIZES & Semantics)
Type ID Bytes Decoding Typical Semantic
1..4 4..16 Float32 (x1..x4) Position (attr 0), Texture UV (attr 5/6/7)
5 4 UByte4N (b / 127.5) - 1.0 Normal (attr 1), Tangent, Binormal
6..7 8 / 4 SInt16 / Byte Skin Weights/Indices Bone indices/weights (.ghg skinned meshes)
8..9 4 / 4 BGRA8 / RGBA8 Vertex Color Baked tint/AO (attr 2; remap all-zero black to white 1,1,1)
10 4 HalfFloat2 (IEEE 754 binary16) Compressed UV / Pos
11 2 UInt16 Packed index / scalar

Triangle Winding & PSID Binding: prim_tp == 1 denotes a Triangle Strip with alternating parity per segment (s & 1 == 0 → CCW (a,b,c); odd → (a,c,b)); prim_tp == 0 or 4/5 denotes a Triangle List. PSID maps each 0xB300/0x8003 draw command opcode directly to an LTMU material index and inline DDS / NU2T texture slice.

Cross-Format Relationships & Dependencies

Referenced By (Upstream Containers / Loaders)

  • .DAT / .HDR — Loaded per level directory (levels///_nxg.gsc).
  • .led Level Editor — Places lights, triggers, cameras, and instances inside the .gsc room origin.
  • .res Manifest — Preloads .gsc geometry alongside paired .nxg_textures and .ps3_shaders in Era 4.

References (Downstream Assets / Sub-Formats)

  • .tex / .nxg_textures — Material texture slots resolve to external .tex or paired .nxg_textures in Era 4.
  • .ps3_shaders / .pc_shaders — HSCB / DXBC shader bytecode resolved via LTMU/TDML shader references.
  • .por Visibility Portals — Subdivides large .gsc room cells across doorway portals.

Filtering, Edge Cases & Unresolved Fields

  • PS3 CellGcm / DDS Linear Pitch Bug: Inline DDS slices in Era 3c–4 often encode an incorrect dwPitchOrLinearSize at +0x14; recompute max(1,(w+3)>>2)*max(1,(h+3)>>2)*(8 if DXT1 else 16) before decoding.
  • unk1 != 0 Shadow/Depth Pre-Passes: Mesh descriptors with unk1 != 0 duplicate visible geometry for depth/shadow passes and contain no new visual draw calls.
  • PC Little-Endian Vertices in Big-Endian HSEM: Test up to 16 Float32 positions; pick LE if BE yields non-finite values, |c| > 10000, or sub-normal magnitudes < 1e-12.

Standalone Clean-Room Parser Pseudocode

function ParseSceneGeometry(buf):
    if buf[0:4] == b"NU20": return ParseNu20Stream(buf)
    if buf[0:4] == b"02UN" or HasTag(buf[:512], "GSNH"): return ParseNu20Container(buf)
    hsem = FindTag(buf[:524288], "HSEM")
    if hsem < 0: return []
    p = hsem + 4; ver = ReadU32BE(buf, p); p += 4
    if buf[p:p+4] == "ROTV" or ver >= 0xAD: p += 4
    mesh_count = ReadU32BE(buf, p); p += 4
    ltmu = FindTagFrom(buf, p, "LTMU"); psid = FindTagFrom(buf, p, "PSID")
    // Decode vertex buffers (handling DXTV when ver >= 0xA1 and shared 0xC000xxxx refs),
    // index buffers (u16be / u32be), LOGH LOD 0 filtering, PSID -> LTMU -> DDS binding,
    // and quantized bounding-box deduplication.
    return ExtractHsemSubmeshes(buf, p, mesh_count, ver, ltmu, psid)
