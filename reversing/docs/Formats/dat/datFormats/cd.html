Overview & EdFile StreamInfo Format

Starting in Era 3 (NXG), character definitions moved from plaintext scripts to TT Games' reflected binary serializer (EdFile / NuSerializer). Every .cd, .cpd, .as, .apj, and .led file begins with a 4-byte version/type tag, a 4-byte string length (0x0A = 10), and the ASCII string StreamInfo at offset 0x08, followed by reflected tables:

  • TypeList: Primitive and composite data types (int, float, CharString, NuVec).
  • ClassList: C++ class schemas with member names and type indices.
  • OLST (Object List) & MOBJ (Main Object): Serialized object instances.
