Binary 64-Byte Header Layout (Big-Endian)

PS3 MSFC (.msf) Header Fields
Offset Size Type Field Observed Example (dx_loki_overhere2_mex.msf)
0x00 4 char[4] magic "MSFC" (0x4D534643).
0x04 4 u32be codec_id 0 PCM BE, 1 PCM LE, 3 MP3 (observed), 4..6 ATRAC3plus.
0x08 4 u32be channels 1 (mono) or 2 (stereo).
0x0C 4 u32be data_size Audio payload bytes (30816 = 30880 - 64).
0x10 4 u32be sample_rate e.g. 44100 Hz (0xAC44) or 48000 Hz.
0x14..0x3F 44 u32be[] flags / loop_pts Loop markers & reserved padding (`0xFFFFFFFF` = no loop).

Standalone Clean-Room Parser Pseudocode

function ParseMsf(buf):
    if buf[0:4] != b"MSFC": raise NotMsf
    codec, ch, sz, rate = ReadU32BE4(buf, 4)
    return {codec: codec, channels: ch, rate: rate, payload: buf[64 : 64 + sz]}
