Timeline Variant Comparison

Cutscene & Blend-Shape Binary Headers
Extension Titles Header Layout
.cut / .cu2 / .cc2 LSW1 .. HP 5–7 Nu2 cutscene container: 4B version (0x02050000 BE or LE) + pointer fixup table (26 ec 00 00 etc.) pointing to camera splines, actor tracks, and dialogue triggers.
.cbs TCS (2,307), BM1 (1,862), CW (1) Character Blend Shape / lip-sync timeline sharing the exact Nu2 pointer-fixup architecture (+0x00 u32be 2 + packed frame/weight keys at +0x90..). Often confused with .cbx speech audio.
.cu3 BM2 (206), LOTR (259), Marvel 1 (312), Hobbit (339), Dim (448) +0x00 u32be 1, +0x04 f32be duration_flags, +0x08 f32be fps (30.0), +0x18 u32be file_size, section offset table (+0x20..), and embedded "DINA" cutscene animation stream.

Cross-Format Relationships & Dependencies

Referenced By (Upstream Containers / Loaders)

  • .scp / .sf / .led — Triggered at level intro/outro or mid-level gates.
  • .cd / .cbs — Character dialogue events bind .cbs lip-sync tracks.

References (Downstream Assets / Sub-Formats)

  • .sub / .subopt — Synchronized subtitle timing files in cut//.
  • .msf / .xma / .cbx — Voiceover audio tracks played during cutscene playback.

Filtering, Edge Cases & Unresolved Fields

  • .cu3 Minus-1 Header Variant: Some Marvel 1 loading-screen .cu3 files (01_grandcentral_ls_nxg.cu3) open with 0xFFFFFFFF (signed -1) followed by u32be 1, 0x12, "DINA".

Standalone Clean-Room Parser Pseudocode

function IdentifyTimeline(buf):
    w0 = ReadU32BE(buf, 0)
    if w0 == 1 or w0 == 0xFFFFFFFF:
        return {kind: "CU3", dina_off: FindTag(buf, b"DINA"), len: len(buf)}
    return {kind: "NU2_Timeline", ver_be: w0, len: len(buf)}
