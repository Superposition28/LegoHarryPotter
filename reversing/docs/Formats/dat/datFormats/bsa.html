Overview

In LEGO Star Wars: The Video Game (2005) and LEGO Star Wars II (2006), almost every character .ani or .an3 file is accompanied by a small .bsa file (typically 50–400 bytes, e.g. chars\amidala\explode.bsa = 82 B, byte-identical between PS2 and Xbox). LSW2 also introduces .anl (Animation List, 184 files) grouping character animation sets prior to the adoption of StreamInfo .as files in Era 3.
