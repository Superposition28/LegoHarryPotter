Filtering, Edge Cases & Unresolved Fields

  • PS3 CellGcmTexture Unswizzling: Non-DXT uncompressed formats in Era 2 PS3 .tex use Morton Z-order swizzling unless bit 5 (0x20, linear) is set in gcm_fmt.
  • DXT Linear Pitch Repair: As in .ghg/.gsc, recompute DXT mip0 pitch when converting Era 3–4 DDS textures.

Standalone Clean-Room Parser Pseudocode

function DecodeTex(buf):
    if buf[0:4] == b"DDS ":
        return PatchPitchAndDecodeDDS(buf)
    if buf[4:8] == b".CC4":
        // Era 4 .nxg_textures (.CC4HSER -> .CC4TSXT + #CONVDAT): scan embedded DDS or TSXT slices
        return ExtractTsxtTextures(buf)
    // Era 2 PS3 CellGcm .tex
    w = ReadU32BE(buf, 4); h = ReadU32BE(buf, 8)
    has_path = (buf[0x0C] >= 0x20 and buf[0x0C] < 0x7F)
    pix_off = ReadU32BE(buf, 0x40) if has_path else 0x40
    return {width: w, height: h, payload: buf[pix_off:]}
