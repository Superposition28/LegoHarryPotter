Binary emitter configuration tables storing named particle effects, spawn counts, lifetimes, and linked texture/shader references.

Header
u32le header_flags, u32le, u32le emitter_count, followed by named emitter blocks ("7VB_SPRAY2", "LLF"...)

Binary Structure (Observed in vfx_7asgardb.ptl)

.ptl Emitter Header
Offset Size Type Field Description
0x00 4 u32le ver_or_sz Observed 0x4B (75) in Era 4.
0x04 4 u32le reserved 0.
0x08 4 u32le emitter_count Count of named emitters (e.g. 4: 7VB_SPRAY1..4).

Filtering, Edge Cases & Unresolved Fields

Standalone Clean-Room Parser Pseudocode

function ParsePtlHeader(buf):
    v, z, n = ReadU32LE3(buf, 0)
    return {version: v, emitter_count: n}
