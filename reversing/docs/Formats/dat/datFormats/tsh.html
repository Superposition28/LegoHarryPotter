Overview & Structure (NuTextureSheet / TSH.cs)

.tsh files appear in two closely related forms across Era 3–4:

  • NU20 / 02UN TSHR (LE) / RHST (BE): Aliases shared textures across character packages.
  • 4CC.TXSH (NuTextureSheet): Contains a NU20 header followed by an array of texture sheet entries mapping FNV1UPPER (offset basis 0x811C9DC5, prime 0x199933) hashes or relative .tex paths to UV sprite sub-rectangles for UI icons and minifigure decals.
