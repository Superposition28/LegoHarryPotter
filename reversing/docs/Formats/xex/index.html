Filtering, Edge Cases & Unresolved Fields

  • Redump Xbox/X360 ISOs contain an outer security/video partition before the XDVDFS game partition (typical offsets: 0x18300000 for Original Xbox, 0x0FD90000 or 0x02080000 for X360); scan candidates for MICROSOFT*XBOX*MEDIA at base + 32*2048.

Standalone Clean-Room Parser Pseudocode

function FindXdvdfsBase(iso):
    for base in [0, 0x18300000, 0x0FD90000, 0x02080000]:
        if iso.ReadAt(base + 32*2048, 20) == "MICROSOFT*XBOX*MEDIA":
            return base
    raise NotXdvdfs
