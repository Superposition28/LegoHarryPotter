## What is This?

This project is a reverse-engineering research toolset and asset extraction pipeline for *LEGO Harry Potter* titles developed by TT Games.

Rather than distributing copyrighted assets, the `RemakeEngine` automates the process of taking a user's legally acquired game files, analyzing proprietary package formats, extracting assets, and converting them into modern open standards.

## Supported Game Targets & Platforms

This module targets both original 7th-generation console releases and modern 8th-generation remasters:

- **LEGO Harry Potter: Years 1-4 (PS3 & Xbox 360):** 7th-gen retail disc releases using big-endian TT Games engine architectures (`PakDat v1.01` `.DAT` archives, `LZ2K` compression).
- **LEGO Harry Potter: Years 5-7 (PS3 & Xbox 360):** 7th-gen retail disc releases with expanded data layouts and updated compression structures.
- **LEGO Harry Potter: Collection (PC / Steam 64-bit):** Remastered collection featuring 64-bit Windows executables (`harry1.exe` / `harry2.exe`), trailing TOC `.datwin` archives, and `LZHAM` compression.
- **Kiosk / Promotional Demos (Xbox 360):** XDVDFS / STFS (PIRS) containers and early retail slicing representations.

## Packaging & Asset Architecture

TT Games employs proprietary archive and compression formats across their titles. Key technical findings from format analysis:

1. **PS3 & Xbox 360 `PakDat v1.01` (`GAME*.DAT`):**
   - Header fields occupy 57 bytes: `[0x00] int32 RawTocOffset` (if `< 0`, `TocOffset = (-RawTocOffset) << 8`), `[0x04] uint32 TocSize`, and a 49-byte signature including NUL at `[0x08..0x38]`: `BEGIN_APP_ID_STRINGPakDat v1.01END_APP_ID_STRING\0`.
   - Standalone archives with a trailing TOC (`Version = -4`, `TocOffset + TocSize == FileSize`) containing 16-byte `PakDatFileEntry[N]`, 8-byte `PakDatNameNode[M]` directory tree, `StringTable[S]`, and `uint32 PathHashes[N]`.
   - Compressed entries (`CompressionType == 2`) use 32 KB chunked **`LZ2K`** compression.
2. **PC Collection `datwin` (`*.datwin`):**
   - 16-byte header storing `int64 TocOffset` and `uint64 TocSize` pointing to a **trailing Table of Contents** (`Version = -1`, `TocSize == 8 + 28 * FileCount`).
   - Contains 24-byte `DatwinFileEntry[N]` records (64-bit `DataOffset` at `+0x00`, canary `0x12345678` at `+0x08`) followed by `uint32 PathHashes[N]` hashed with `TtPathHash` (`seed 0x811C9DC5`, `prime 0x00199933`).
   - Compressed entries (`Flags == 0x04040404`, `CompressionType == 4`) use **`LZHAM`** (`0E C6` header, `DictSizeLog2 = 15`, `DecompressFlags = 5`, trailing Adler32).
3. **Xbox 360 Containers:**
   - Retail packages use `XEX2` executables (`Default.xex`) and standard `GAME*.DAT` archives.
   - Demo discs use `PIRS` (STFS) packages inside XDVDFS partitions embedding `Default.xex` and sliced `GAME*.DAT` volumes.
4. **Launcher Package (`launcher.pkiwin` / `launcher.pkdwin`):**
   - Paired index/data architecture using zlib compression (`0x785E`).
5. **Direct3D Shader Blobs (`*.blob`):**
   - Consolidated D3D11 bytecode caches (`shaderblob_pc.blob` and `harry2_shaderblob_pc.blob`).

## File Breakdown

- `operations/` — Extraction and conversion scripts:
  - `lhp_dat.bms` — QuickBMS extraction script for `PakDat v1.01` (`.dat`) archives across PS3 and Xbox 360.
- `reversing/` — Research utilities and inspection tools:
  - `tools/InspectPakDat.ps1` — Fast PowerShell/C# inspector for console `PakDat v1.01` archives; validates TOC offsets, reconstructs paths, and checks FNV-1a hashes.
  - `tools/InspectDatwin.ps1` — Inspector for PC Collection `.datwin` archives; checks trailing TOC invariants, canaries, and cross-matches hashes.
  - `tools/InspectXbox360Demo.ps1` — STFS / PIRS container inspector for Xbox 360 kiosk demo packages.
  - `tools/ExtractArchive.ps1` — Unified extractor for `PakDat v1.01` (LZ2K) and `.datwin` (LZHAM) archives.
  - `tools/ComparePlatforms.ps1` — 3-way quantitative comparison utility across PS3, Xbox 360, and PC builds.
- `operations.toml` — RemakeEngine operations manifest defining tool downloads, disc image unpacking, and archive extraction operations.
- `Tools.toml` — Toolchain manifest declaring managed dependencies (Blender, QuickBMS, vgmstream, FFmpeg, ImageMagick).
- `Readme.md` — This file.
- `TODO.md` — Module development roadmap and milestones.
- `.gitignore` — Ignore rules for user game sources, extracted assets, local logs, and generated configs.

## Operations Overview & How To Use

The new [cross-reference workflow](../../research/cross-reference/Evidence-and-commands.md) uses MoonSharp through direct Remake Engine CLI arguments. Operations 10/11 inventory TT archives and extract the Windows Collection; 12/13 inspect/extract the Collection launcher and supplied demo container; 14 compares both modules' exported inventories; 15 validates the archive parser with synthetic inputs. All newly added game scripts are under `operations/` and import the shared parent Lua implementation in a co-located LEGO checkout. Existing standalone PowerShell tools below are historical research references, not the execution path for this workflow.

This module is designed to be executed through the RemakeEngine CLI or TUI.

### Declared Operations in `operations.toml`

| ID | Name | Type | Description |
|---|---|---|---|
| `-1` | Download Required Tools | `engine` | Downloads and unpacks tools declared in `Tools.toml`. |
| `1` | Extract Archives (.DAT) - PS3 | `bms` | Extracts `GAME*.DAT` archives from PS3 sources using `operations/lhp_dat.bms`. |
| `2` | Extract Archives (.DAT) - Xbox 360 | `bms` | Extracts `GAME*.DAT` archives from Xbox 360 sources using `operations/lhp_dat.bms`. |
| `3` | Extract ISO Disc Image - PS3 | `engine` | Extracts PS3 retail disc image (`.iso`) placed in `Source/Orginals/PS3`. |
| `4` | Extract ISO Disc Image - Xbox 360 | `engine` | Extracts Xbox 360 retail disc image (`.iso`) placed in `Source/Orginals/Xbox_360`. |

### Running via RemakeEngine CLI

From the RemakeEngine repository root (`A:\RemakeEngine\Main`):

```pwsh
# 1. List available operations for this module:
dotnet run -c Debug --project .\EngineNet\ -- --list-ops '.\EngineApps\Games\Lego\Games\Lego_Harry_Potter'

# 2. Download managed tools declared in Tools.toml (Blender, QuickBMS, FFmpeg, etc.):
dotnet run -c Debug --project .\EngineNet\ -- --game_module '.\EngineApps\Games\Lego\Games\Lego_Harry_Potter' --run_op -1

# 3. Extract PS3 archives (.DAT):
dotnet run -c Debug --project .\EngineNet\ -- --game_module '.\EngineApps\Games\Lego\Games\Lego_Harry_Potter' --run_op 1

# 4. Extract Xbox 360 archives (.DAT):
dotnet run -c Debug --project .\EngineNet\ -- --game_module '.\EngineApps\Games\Lego\Games\Lego_Harry_Potter' --run_op 2
```

## Standalone Reversing Tools (`reversing/tools/`)

The PowerShell scripts under `reversing/tools/` can also be run independently to inspect or extract user game archives:

```pwsh
# Inspect PS3/Xbox 360 PakDat v1.01 archive:
& '.\reversing\tools\InspectPakDat.ps1' -SourceRoot 'path\to\GAME.DAT' -VerifyHashes

# Inspect PC Collection .datwin archive:
& '.\reversing\tools\InspectDatwin.ps1' -CollectionRoot 'path\to\harry1.datwin' -ResolvePaths

# Extract an archive using native LZ2K/LZHAM decompression:
& '.\reversing\tools\ExtractArchive.ps1' -ArchivePath 'path\to\archive.DAT' -OutputDir 'path\to\output'
```

## Toolchain & Requirements

Managed tools are declared in `Tools.toml` and automatically downloaded by RemakeEngine when executing Operation `-1`:

- **QuickBMS 0.12.0:** Script-based archive extraction for legacy packages.
- **Blender 4.5.4:** 3D model and geometry conversion.
- **vgmstream-cli (r2023):** Multi-stream audio decoding and playback.
- **FFmpeg 8.0:** Bink / video transcoding.
- **ImageMagick (7.1.2):** Texture surface and format conversions.
